# arabica-11 (sunset)

The `arabica-11` testnet has been sunset and is no longer running. The files in this directory are kept for historical reference only and should not be used to start a new node.

The final state of the chain is preserved in [final_state_export.json](./final_state_export.json).

Arabica has been replaced by the [corto-1](../corto-1) testnet. See the [root README](../README.md) for the list of active networks.
